# Markdown Preview 紧凑宽版排版设计

## 目标

在不牺牲移动端可读性的前提下，让桌面端 Markdown 预览更接近传统 markdown-preview 的紧凑排版：减小正文、标题和纵向间距，同时扩大预览卡片及其父级工具栏的可用宽度。

## 设计方案

### 外层布局

- `document-toolbar` 与 `preview-container` 的桌面端最大宽度从 `960px` 提升到 `1200px`。
- 保持水平居中、窄视口下 `width: 100%` 的现有行为。
- 不改变三栏应用框架、侧栏宽度或 iframe 高度，避免扩大本次调整范围。

### Markdown 阅读区

- `#preview-root` 最大宽度从 `860px` 提升到 `1040px`。
- 桌面端正文从 `17px / 1.76` 调整为 `16px / 1.6`。
- 缩小桌面端左右内边距，使增加的容器宽度能转化为实际内容宽度，同时保留清晰的阅读留白。
- 正文块默认纵向间距从 `1.1em` 收紧到约 `0.9em`。

### 标题层级

- `h1` 桌面端最大字号约为 `44px`。
- `h2` 调整为 `25px`，`h3` 调整为 `20px`。
- 各级标题的上下间距同步略微收紧，保持清晰层级但减少长文滚动距离。
- 保留现有字重、字间距、分隔线和主题配色。

### 响应式与导出

- 移动端保持 `16px` 正文字号，不进一步压缩；仅按需要校准标题尺寸，确保窄屏可读。
- 导出 HTML 使用与预览一致的正文宽度、字号、行高、标题尺寸和块间距，避免预览与导出结果产生明显差异。

## 实现边界

- 只调整排版尺度和容器宽度，不修改组件结构、渲染逻辑、主题、侧栏或交互。
- 样式源文件以 `preview/src/styles.css`、`preview/src/preview/preview.css` 和 `preview/src/export.js` 为准。
- 不修改旧版 `app/_static/markdown.css`，因为当前 React preview 使用独立样式入口。

## 验证标准

- 桌面端工具栏和预览卡片最大宽度为 `1200px`，Markdown 阅读区最大宽度为 `1040px`。
- 正文计算样式为 `16px / 1.6`，标题和块间距按设计收紧。
- 小于等于 `640px` 时正文仍为 `16px`，页面无横向溢出。
- 导出样式与 iframe 预览的关键排版参数一致。
- 现有 preview 测试、lint 和构建通过；新增或更新样式断言覆盖关键尺寸。
