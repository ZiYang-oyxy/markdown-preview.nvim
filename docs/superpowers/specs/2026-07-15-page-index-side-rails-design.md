# 书页索引侧栏设计规格

## 目标

让桌面端左右侧栏在收起后完全退出布局，把空间还给 Markdown 正文，同时通过贴在阅读区边缘的“书页索引”把手保留清晰、可访问的恢复入口。

## 用户与任务

- 用户：在本地阅读、整理 Markdown 的开发者和写作者。
- 页面核心任务：舒适阅读当前文档，并能快速访问临时文档和本文目录。
- 本次只改变宽屏桌面侧栏；移动端继续使用现有 Sheet。

## 视觉方向

- 色彩沿用现有 `Paper / Ink / Rule / Signal Blue / Quiet Blue` token，不引入新主题。
- 展开侧栏保持平整、克制；收起按钮进入侧栏标题区，不再悬浮在分割线上。
- 收起后 rail 宽度为 `0`，其背景和分割线一并消失。
- 阅读区左右边缘各可出现一个窄竖向“书页索引”把手，使用图标和中文语义标签“文档”或“目录”。
- 把手采用小直角圆角和轻微定向阴影，不使用圆形箭头、胶囊或玻璃拟态。

## 交互

1. 点击展开侧栏标题区的收起按钮，侧栏宽度在约 `220ms` 内变为 `0`，正文同步扩展。
2. 对应的书页索引把手出现在阅读区边缘；按钮保持可见焦点和至少 40px 的可点击宽度。
3. 点击把手恢复侧栏；把手随即消失。
4. 左右侧栏状态相互独立，并继续保存到现有 `rails` preference。
5. `prefers-reduced-motion: reduce` 下取消布局与把手动效。

## 可访问性

- 展开态按钮继续使用 `aria-expanded`，并提供“收起临时文档栏”或“收起本文目录栏”的标签。
- 收起态把手使用 `aria-expanded="false"` 和“展开临时文档栏”或“展开本文目录栏”的标签。
- 图标仅作装饰，中文“文档 / 目录”作为可见文本。
- 键盘焦点不得被阅读区或侧栏的 overflow 裁切。

## 响应式边界

- `min-width: 1180px` 显示桌面 rail 和书页索引把手，沿用现有桌面断点。
- 低于该断点时沿用现有移动端 header actions 与 Sheet，不显示桌面把手。
- 正文现有 `960px` 最大阅读宽度保持不变；收起侧栏释放的是呼吸空间与居中位置，不拉宽正文行长。

## 验收标准

- 收起任一 rail 后，其 Grid 列宽为 `0px`，不存在遗留的 40px 空轨道或分割线。
- 左右把手只在各自 rail 收起时出现，文案和方向正确。
- 展开 rail 的收起按钮位于标题区；目录 rail 也有明确标题行。
- 刷新后收起状态保持。
- 宽屏、窄屏、键盘焦点、深色主题和 reduced motion 均无回归。
